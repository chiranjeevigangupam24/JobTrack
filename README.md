
# JobTrack Pro — Job Application Management System

A complete full-stack job application and interview pipeline platform featuring:
- **Interactive Web Dashboard:** HTML5 + Tailwind CSS + React 18
- **RESTful Backend Connection:** FastAPI + Uvicorn + Pydantic
- **Offline CLI Application:** Pure Python standard library menu interface
- **Atomic Persistence & CSV Safety:** Zero-corruption JSON storage and spreadsheet formula injection defense

---

## 🚀 Running the Project

### 1. Launch the Web Dashboard (FastAPI + React):
```powershell
python server.py
```
- Open in Browser: **[http://localhost:8000](http://localhost:8000)**
- Interactive API Docs: **[http://localhost:8000/docs](http://localhost:8000/docs)**

### 2. Launch the Terminal CLI:
```powershell
python main.py
```

### 3. Run Unit Tests:
```powershell
python -m unittest discover -s JobTrack/tests -t JobTrack -v
```
